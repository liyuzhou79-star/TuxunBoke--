# TuxunBoke | 图寻博客

欢迎来到 TuxunBoke（图寻博客）的官方介绍仓库！

这是一个摒弃了传统臃肿框架，完全由原生前端与轻量级边缘计算构建的极简独立博客平台。这里没有花里胡哨的设计，只有极致的加载速度、硬核的技术分享与纯粹的阅读写作体验。

## ✨ 核心特性
*   **极简 UI 与丝滑体验**：全站原生 HTML/JS 极致加速，拒绝冗余，追求复古方正的排版与流畅的滑动。
*   **企业级安全风控**：内置无感人机验证系统，并配合设备指纹识别，有效防刷、防爆破与防代理滥用。
*   **丰富的创作生态**：原生支持 Markdown 语法，内置专属“代码库”模块，支持代码高亮与一键复制。
*   **完善的会员与积分体系**：支持代码签到、积分商城、付费内容专享以及发卡系统。
*   **私有化通信系统**：全站内置私信信箱，支持用户与站长互动，系统级物品发货与一键审批通知。

## 🛠️ 技术栈
*   **前端**：原生 HTML5 / CSS3 / Vanilla JavaScript
*   **后端**：轻量级边缘计算 (Edge Workers)
*   **数据库**：Serverless SQLite
*   **图床/CDN**：全球 CDN 加速
